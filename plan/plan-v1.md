# План реализации v1 (после первого раунда согласования)

**Проект:** «Двойник» (приложение для поиска дубликатов файлов)  
**Дата согласования:** 25.11.2026  
**Старт разработки:** 30.11.2026  
**Плановый релиз:** 02.04.2027 (6 итераций по 3 недели)

## Параметры планирования

- Команда: 1 разработчик уровня middle (160 BYN/день).
- Длина итерации: 3 недели = 15 рабочих дней.
- Коэффициент загрузки: 0,8 → 12,0 чел.-дн. за итерацию.
- Планирование, демонстрация, документация: 1,0 чел.-дн. → **ёмкость итерации на функции: 11,0 чел.-дн.**
- Итоговая потребность: **64,0 чел.-дн.** при ёмкости **66,0 чел.-дн.** (резерв 2,0 чел.-дн., 3 %).
- Ориентировочная стоимость: 6 × 15 × 160 = **14 400 BYN**.

## Изменения после первого раунда

- `REQ-FUNC-012` (предпросмотр): встроенный просмотр заменён открытием системной программой (2,0 → 0,5 чел.-дн.).
- `REQ-FUNC-022` (кэш хэшей): бинарный файл вместо SQLite по ADR-0007 (4,0 → 2,5 чел.-дн.; приоритет 40 → 30).
- `REQ-FUNC-023` (сравнение папок): переиспользование ядра поиска (5,0 → 3,5 чел.-дн.).
- `REQ-FUNC-024` (ход сравнения): общий индикатор прогресса (1,0 → 0,5 чел.-дн.).
- `REQ-OBS-001` (журнал): простой текстовый формат (1,5 → 1,0 чел.-дн.).
- `REQ-INT-006` (пустые состояния): текстовые подсказки (1,0 → 0,5 чел.-дн.; приоритет 30 → 40).
- `REQ-FUNC-017` (предупреждение о корзине): стандартный диалог (1,0 → 0,5 чел.-дн.).
- `REQ-FUNC-009` (пауза): отложена (приоритет 40 → 50, не входит в план).
- `REQ-FUNC-021` (экспорт CSV): понижен приоритет (30 → 40).
