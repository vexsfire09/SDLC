## Описание проекта

Настольное приложение для расчёта гликемического индекса (ГИ) и гликемической
нагрузки (ГН) продуктов питания и составных блюд.

Гликемический индекс показывает, насколько быстро углеводы продукта повышают
уровень глюкозы в крови по сравнению с эталоном (чистой глюкозой, ГИ = 100).
Сам по себе ГИ не учитывает количество съеденного, поэтому программа
дополнительно рассчитывает гликемическую нагрузку по формуле
`ГН = ГИ × (углеводы на порцию, г) / 100`, которая даёт более практичную оценку.

Основные функции:

- ведение справочника продуктов с указанием ГИ и содержания углеводов на 100 г;
- расчёт ГИ и ГН для заданной массы продукта;
- расчёт итогового ГИ составного блюда как средневзвешенного по вкладу
  углеводов каждого ингредиента;
- классификация результата по категориям: низкий, средний, высокий;
- сохранение и загрузка пользовательских рецептов.

Целевая аудитория — люди, контролирующие рацион по медицинским показаниям
(сахарный диабет, инсулинорезистентность) или в рамках диеты, а также
специалисты по питанию.

Приложение носит справочный характер и не заменяет консультацию врача.
