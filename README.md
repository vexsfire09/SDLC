# «Двойник» — приложение для поиска дубликатов файлов

**Автор:** Левшук Д.Д., группа 434701
**Дисциплина:** Жизненный цикл разработки программного обеспечения
**Учреждение:** БГУИР, кафедра ЭВМ

## Описание проекта

Настольное однооконное приложение для Windows, которое находит на компьютере
файлы с одинаковым содержимым (независимо от имени) и помогает безопасно
избавиться от лишних копий.

Основные функции:

- поиск дубликатов по содержимому в одной или нескольких папках, с подпапками;
- фильтры по типу файлов, размеру и исключённым папкам;
- просмотр групп дубликатов и объёма места, которое можно освободить;
- автовыбор лишних копий по правилу (самый новый, самый старый, короткий путь, приоритетная папка);
- перемещение в корзину, перемещение в папку или удаление навсегда с подтверждением;
- защита от удаления всех копий файла;
- экспорт результатов в CSV, кэш хэшей для быстрого повторного поиска;
- сравнение двух папок (например, оригинала и резервной копии).
