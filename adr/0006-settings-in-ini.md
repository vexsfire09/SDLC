# Хранение настроек в INI-файле через QSettings

## Контекст и постановка задачи

Приложение должно сохранять настройки, список папок поиска, фильтры, исключённые и защищённые папки между запусками (REQ-FUNC-025, REQ-FUNC-026) строго в папке `%LOCALAPPDATA%\Dvoinik` (REQ-SEC-004), без записи в реестр Windows, чтобы обеспечить портативность и чистое удаление (REQ-INST-001).

## Драйверы решения

* Хранение всех данных в одной папке `%LOCALAPPDATA%\Dvoinik` (REQ-SEC-004).
* Простота чтения/записи и автоматическое восстановление значений по умолчанию при повреждении (REQ-REL-003).
* Отсутствие внешних библиотек.

## Рассмотренные варианты

* INI-файл через `QSettings(path, QSettings::IniFormat)`
* Реестр Windows (`QSettings` по умолчанию на Windows)
* JSON-файл (`QJsonDocument`)

## Итог решения

Выбранный вариант: «INI-файл через `QSettings(path, QSettings::IniFormat)`», потому что он встроен в Qt, хранит всё в одном текстовом файле `settings.ini` в профиле пользователя и легко читается при отладке.

### Последствия

* Хорошо, потому что настройки не засоряют реестр Windows и удаляются вместе с папкой `%LOCALAPPDATA%\Dvoinik`.
* Хорошо, потому что минимальный объём кода в `SettingsStore`.
* Плохо, потому что вложенные структуры в INI неудобны (для данного приложения достаточно плоских ключей и списков строк).

### Подтверждение

Проверка сохранения и восстановления настроек после перезапуска, а также запуска при повреждённом `settings.ini` (REQ-FUNC-026, REQ-REL-003).

## Плюсы и минусы вариантов

### INI-файл (QSettings)

* Хорошо, потому что встроен в Qt, хранится в каталоге данных приложения, читаем человеком.
* Плохо, потому что плохо подходит для сложных вложенных объектов.

### Реестр Windows

* Хорошо, потому что стандартно для Windows.
* Плохо, потому что нарушает REQ-SEC-004 и REQ-INST-001 (удаление сводится к удалению двух папок).

### JSON-файл

* Хорошо, потому что поддерживает вложенность.
* Плохо, потому что требует больше кода сериализации и проверки типов для простых пар «ключ – значение».

## Дополнительная информация

Затрагивает требования: REQ-FUNC-025, REQ-FUNC-026, REQ-SEC-004, REQ-REL-003, REQ-INST-001. Элемент SDD: `004-information` (`SettingsStore`).
